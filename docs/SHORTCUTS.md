## General Shortcuts

### Application Control
- **Ctrl + N**: Create new project
- **Ctrl + O**: Open existing project
- **Ctrl + S**: Save current work
- **Ctrl + Shift + S**: Save as
- **Ctrl + W**: Close current tab/window
- **Ctrl + Q**: Quit application
- **Ctrl + P**: Print current document/view
- **Ctrl + F**: Find content
- **Ctrl + H**: Replace content
- **F1**: Open help system
- **F12**: Developer tools (if enabled)

### Window Management
- **Ctrl + Tab**: Switch between open modules/tabs
- **Ctrl + Shift + Tab**: Switch to previous module/tab
- **Alt + Left Arrow**: Navigate back
- **Alt + Right Arrow**: Navigate forward
- **Ctrl + 1-9**: Quick access to modules 1-9
- **Ctrl + 0**: Reset zoom level
- **Ctrl + Plus (+)**: Zoom in
- **Ctrl + Minus (-)**: Zoom out

### System Shortcuts
- **Ctrl + C**: Copy selected content
- **Ctrl + V**: Paste copied content
- **Ctrl + X**: Cut selected content
- **Ctrl + Z**: Undo last action
- **Ctrl + Y**: Redo last action
- **Ctrl + A**: Select all content
- **Ctrl + D**: Delete selected item
- **Ctrl + L**: Focus on search/address bar
- **Ctrl + R**: Refresh/reload current view

## Custom Shortcuts

### Creating Custom Shortcuts
1. **Open Settings**: Go to Settings > Keyboard Shortcuts
2. **Add Shortcut**: Click "Add Custom Shortcut"
3. **Assign Action**: Choose the action to assign
4. **Set Keys**: Press the key combination you want to use
5. **Save**: Confirm and save your custom shortcut

### Best Practices for Custom Shortcuts
- **Avoid Conflicts**: Don't override existing system or application shortcuts
- **Logical Grouping**: Group related shortcuts with similar key combinations
- **Memorable Patterns**: Use intuitive key combinations
- **Document Your Shortcuts**: Keep a reference of your custom shortcuts
- **Use Modifiers**: Combine Ctrl, Alt, Shift with letters/numbers
- **Consider Ergonomics**: Use comfortable key combinations

### Example Custom Shortcuts

## Tips for Using Shortcuts

### Learning Shortcuts
1. **Start with Basics**: Learn essential shortcuts first
2. **Practice Regularly**: Use shortcuts consistently to build muscle memory
3. **Use Help System**: Press F1 or check help for module-specific shortcuts
4. **Customize**: Create custom shortcuts for your most-used features
5. **Gradual Adoption**: Add new shortcuts gradually rather than all at once

### Shortcut Efficiency
- **Combine Shortcuts**: Use multiple shortcuts in sequence for complex tasks
- **Context Awareness**: Different shortcuts work in different contexts
- **Modifier Keys**: Master the use of Ctrl, Alt, Shift, and Windows keys
- **Function Keys**: Learn F-key shortcuts for quick access
- **Mouse + Keyboard**: Combine mouse clicks with keyboard modifiers

### Troubleshooting Shortcuts
- **Check Conflicts**: Ensure no conflicts with system or other application shortcuts
- **Update Settings**: Check if shortcuts are enabled in settings
- **Restart Application**: Sometimes shortcuts need a restart to take effect
- **Reset Shortcuts**: Reset to default if custom shortcuts cause issues
- **Check Documentation**: Refer to module-specific documentation for shortcuts

### Accessibility Shortcuts
- **Ctrl + Shift + I**: High contrast mode
- **Ctrl + Shift + +**: Increase text size
- **Ctrl + Shift + -**: Decrease text size
- **Ctrl + Shift + 0**: Reset text size
- **F7**: Spell check (if available)
- **Ctrl + Shift + A**: Accessibility options

This comprehensive list of keyboard shortcuts will help you work more efficiently in PotomacAnalyst. Remember to practice regularly and customize shortcuts to fit your workflow preferences.
